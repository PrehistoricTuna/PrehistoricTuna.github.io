# Agent notes

This repository is the published static site for [PrehistoricTuna.github.io](https://prehistorictuna.github.io/). It was generated by Hexo 3.8.0; the Hexo source tree is not in this repo.

## Cursor Cloud specific instructions

- There is no `package.json`, test suite, or application server to install.
- Serve the site with Python's built-in HTTP server:

  ```bash
  python3 -m http.server 8080 --bind 0.0.0.0
  ```

- Open [http://127.0.0.1:8080/](http://127.0.0.1:8080/) for Home, `/archives/` for Archives, and `/2019/04/17/我的第一篇文章/` for the sample post.
- Smoke-check with:

  ```bash
  curl -fsS http://127.0.0.1:8080/ | grep -q PrehistoricTuna
  ```
